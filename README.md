# Volcano explorer

A Shiny app to overlay several DESeq2 results on a single volcano plot and follow gene lists from one experiment to the next.

**Live app:** `https://alicejegou.github.io/RNAseq-volcano-explorer/`

The app runs entirely in your browser thanks to [Shinylive](https://posit-dev.github.io/r-shinylive/) (R compiled to WebAssembly). There is no server: **your data never leaves your computer**. The first load can take a few seconds while R and the packages start up.

## Features

- One base experiment plus any number of overlay experiments, each with its own color and legend name.
- Unlimited gene lists, each with its own color, display switches and source (typed list, common DEGs, top N).
- Links between the positions of the same gene across experiments.
- Cross-table of the listed genes: sortable, filterable, with interactive hover and CSV export.
- Lasso / box selection on the plot, which can be turned into a new gene list.
- Exports: PNG plot and several CSV tables.

Required packages: `shiny`, `ggplot2`, `dplyr`, `scales`, `plotly`, `jsonlite`, `htmlwidgets`.

```r
install.packages(c("shiny", "ggplot2", "dplyr", "scales",
                   "plotly", "jsonlite", "htmlwidgets"))
shiny::runApp("app/app.R")
```

## Usage

### 1. Data

- **Base experiment**: the reference DESeq2 table (CSV, TSV or `;`-separated, the separator is guessed).
- **Add overlay experiment(s)**: one or more tables to overlay. Successive uploads are added to the previous ones (same file name = replacement). Each overlay has a **Remove** button.
- **Restrict to genes of a list** (optional): keeps only the genes of a list in all tables (for example genes with a DAP peak).
- **Clear overlay** removes the overlays, **Clear all** resets everything.

For each experiment you can set the color, the legend name and, under "Columns", the Gene ID, log2FC and padj columns. They are guessed from the header names, and an unnamed first column (row names) becomes `X`.

### 2. Gene lists to highlight and link

Each list block has:

- a name and a color;
- three independent switches:
  - **Highlight**: ring and highlighted points;
  - **Links**: segments from the base experiment to the other experiments;
  - **Names**: gene names (off by default);
- a source:
  - **Gene list**: typed or uploaded genes (separated by space, comma, semicolon or newline);
  - **DEG common to all experiments**;
  - **Top N DEG of base, by padj**;
  - **Top N DEG of base, by |log2FC|**.

Hiding a highlight does not change the table, the `lists` column, the summary or the tooltips: only the drawing changes. A gene that belongs to several lists gets concentric rings.

### 3. Display

| Setting | Effect |
|---|---|
| Legend title | Title of the experiment legend |
| padj cutoff, \|log2FC\| cutoff | Thresholds that define DEGs |
| X min, X max, Y max | Zoom (empty = automatic) |
| Gene name size | Size of the gene names |
| Plot only the genes passing the main table filters | See below |
| List ring thickness, Listed point size | Look of the listed genes |

### 4. Export

- **Plot (.png)**: image of the plot (1400 x 1000, scale 2).
- **Highlighted genes (.csv)**: the cross-table.
- **Selected on plot (.csv)**: genes selected with the lasso.
- **Full merged table (.csv)**: one row per gene, one block of columns per experiment.

## The cross-table

One row per listed gene: the lists it belongs to, log2FC, padj and DEG status in each experiment, the number of experiments where the gene is found, and a status (`found in all`, `found in some experiments only`, `not found`).

- **Row hover**: a black ring is drawn around the gene on the plot (in every experiment). Hovering a point on the plot also highlights its table row.
- **Sorting**: click a header (ascending, descending, off). Shift + click adds a sort level, shown by a small number. Empty cells always come last.
- **Filters** (one per column, combined with AND):
  - numeric columns: `<0.05`, `>1`, `>-1 <1`, `>=2`, or `abs>1` for the absolute value;
  - `deg_*` columns: TRUE / FALSE / NA menu;
  - text columns: contains.
- **reset sort / filters** clears the table state.
- **Download filtered table (.csv)** exports the visible rows, in the displayed sort order, with full-precision values. With no filter active, the whole table is exported.

### Link with the plot

When a filter is active and the "Plot only the genes passing the main table filters" box is checked, only the listed genes that pass the filter keep their overlay (rings, points, links, names). The background cloud stays visible. This only applies to the main table.

## Selection on the plot

The lasso or box tool in the plot toolbar selects genes, which are listed in the "Selected on the plot" table (at most 200 rows shown, the CSV contains all of them). **Use selection as gene list** creates a new list from the selection, and **Clear selection** clears it.

## Known limitations

- Genes with `NA` or 0 padj have no finite -log10(padj): they are not drawn (they stay in the tables).
- Table sorting and filters are reset when the table is rebuilt (change of cutoff, gene list or file). Toggling Highlight, Links or Names does not rebuild it.
- The plot is redrawn when a table filter changes, so the mouse-wheel zoom goes back to the default. The X min / X max / Y max settings are kept.
- Gene names use `geom_text`, not `ggrepel` (`ggplotly()` cannot convert `geom_text_repel`). For readability, enable Names only on the list you care about.
- The plot uses `toWebGL()` to stay fast with many genes. If labels render badly, remove that call in `renderPlotly`.
